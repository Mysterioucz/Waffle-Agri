# Waffle Agri - Feature Overview

## 📊 Dashboard

**Central hub with real-time insights & AI guidance**

- Farm overview with weather data (temp, humidity, wind, UV, alerts)
- User profile: level, points, streak tracking
- AI daily guidance: weather summary, crop health, recommended tasks
- Active crops display: health status, area size, harvest dates
- Priority-based task list with labor estimates

## 📖 Farm Logbook

**Complete activity tracking & resource management**

- Quick stats: total activities, hours, costs
- Activity logging: 9 types with auto-duration defaults (watering 30min, harvesting 120min, etc.)
- Resource management: track water, fertilizer, pesticide, seeds, equipment with costs
- Timeline view: chronological history with icons & details
- Edit/Delete: full CRUD operations with confirmation dialogs

## 🎮 Gamification

**Reward system to drive engagement**

- Profile cards: level/points, streak counter, badge collection
- Badge system: Lucide icons, rarity levels (Common→Legendary), unlock progress
- Active achievements: category-based (Productivity, Consistency), progress bars, completion tracking
- Rewards store: premium subscriptions, consultations, seed packages - point-based redemption

## 📈 Analytics & Forecasting

**AI-powered predictions & insights**

- Dynamic crop selector from database
- Profit forecast: revenue, costs, profit projections with confidence levels
- Cost breakdown: seeds, fertilizer, labor, equipment
- Market predictions: price trends (rising/falling), 12-month forecast, volatility
- Performance metrics: revenue vs. last season, profit margin, resource efficiency

## 🔧 Technical Stack

**Database:** PostgreSQL + Prisma ORM (20+ models) | **API:** Next.js RESTful endpoints | **Frontend:** Next.js 14 + TypeScript + Tailwind CSS + Lucide Icons | **State:** React Hooks | **Features:** Real-time sync, CRUD operations, responsive design, loading states
